# 快速上手

## 五分钟跑起来

### 1. 拿到程序

三种方式，选一个：

**A. 下载安装包（最简单）**
到 [Releases](https://github.com/imcreazy/DeepSeek-Fengcode/releases/latest) 下载
`Fengcode-*-setup.exe`，运行安装。

**B. 解压即用**
下载 `Fengcode-*-win64.zip`，解压后运行 `Fengcode.exe`。

**C. 从源码跑**
```bash
git clone https://github.com/imcreazy/DeepSeek-Fengcode.git
cd Fengcode/cli
python -m pip install -e .
fengcode serve --open
```

---

### 2. 走一遍首次向导

第一次打开会弹三步向导：

1. **认识能力** —— 说明它会做什么、有哪些防护
2. **配置模型** —— 如果还没配密钥，会引导你去「设置 → 模型服务」
3. **选权限等级** —— 建议选「工作区可改」

每一步都能跳过，跳过之后不再打扰。

---

### 3. 配一个模型

进「设置 → 模型服务」：

1. 里面预置了**万象 API**（地址已填好），把密钥粘进去
2. 点「获取模型」，勾上你要用的
3. 保存，回到对话页

想用别家？点「添加一个服务」，填地址和密钥即可 ——
**任何 OpenAI 兼容接口都能用**（DeepSeek、智谱、通义、Kimi、各类中转站）。

密钥只存在你本机的 `config.toml`，不会上传到任何地方。

## 三个核心概念

### 项目（工作区）

左侧栏是「**项目 > 会话**」两层。

- 点 **+** 新建空白项目，填个名字就行，**目录会自动创建**
- 每个项目绑定一个独立工作目录，会话和文件都归它管
- 项目可重命名、换目录、删除（删项目**不会**动磁盘上的文件）
- 默认项目受保护，不可删除

这样你可以在「网站项目」和「数据分析项目」之间切换，互不干扰。

### 工作模式（可不选）

输入框上方有个模式选择器：

| 状态 | 什么时候用 |
|---|---|
| **自动（不选）** | 默认就用这个。AI 会自己判断该不该先列计划 |
| **计划模式** | 你想先看方案再让它动手 |
| **目标模式** | 一个要跨多轮推进的大目标，让它记住进度 |

计划与目标可以**反选**（点已选的项即取消）。没有「对话模式」这种强制第三态 ——
**不选就是最自然的状态**。

### 权限等级

三档，随时可切：

| 档位 | 行为 |
|---|---|
| **只看不改** | 拒绝一切写操作，纯查询 |
| **工作区可改**（推荐） | 工作区内直接改，越界会先问你 |
| **完全权限** | 全部放行，不再逐条确认 |

更细的控制在「设置 → 权限 → 细粒度规则」：
可以写 `tool:shell`、`cmd:git push`、`path:**/.ssh/*` 这类规则，
优先级 `deny > ask > allow`。

## 常用快捷键

| 按键 | 作用 |
|---|---|
| `Ctrl+K` | 新建会话 |
| `Ctrl+/` | 聚焦输入框 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+I` | 展开/收起右侧面板 |
| `Ctrl+B` | 隐藏/显示左侧栏 |
| `Ctrl+Alt+F` | （桌面端）全局唤起窗口 |

在输入框打 `/` 会弹出**命令与技能**菜单。

## 记忆：让它记住你

「设置 → 记忆」有四个视角：

| 标签 | 看什么 |
|---|---|
| **背景记忆** | 它记住的事实与偏好（跨会话生效） |
| **归档的记忆** | 收起来备查、不参与召回的内容 |
| **指令文件** | `AGENTS.md` 这类每轮自动注入的规矩文件 |
| **召回记录** | 哪些记忆真被用上了、用了多少次 |

两层作用域：**全局**（所有项目共享）与**本项目**（只在当前项目生效）。

想让它记住什么，直接说「记住：我习惯用 PowerShell」就行。

## 出问题怎么办

| 症状 | 处理 |
|---|---|
| 后端起不来 | 桌面端菜单「帮助 → 查看日志」 |
| 配置改坏了起不来 | 设置 → 高级 → **恢复助手** → 回滚 |
| 不确定哪里出问题 | 设置 → 高级 → **恢复助手** → 运行诊断 |
| 端口被占用 | 会自动往后找；也可设环境变量 `FENGCODE_PORT` |
| 命令行找不到 `fengcode` | 用 `python -m fengcode.cli.main <子命令>` |

`恢复助手` 会逐项检查数据目录、依赖、数据库、模型可用性，并给出修复建议；
改配置前它会自动备份，随时能回滚。
