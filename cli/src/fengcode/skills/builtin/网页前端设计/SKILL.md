# 网页前端设计

## 反模式（必须避免）
- ❌ 紫色渐变 + 圆角白卡片 + 居中大标题的"标准 AI 落地页"
- ❌ Inter / Roboto 默认字体配纯黑文字纯白背景
- ❌ 所有元素同样大小的阴影、同样的圆角、同样的间距
- ❌ emoji 当图标、堆砌图标
- ❌ 大段无意义的英文 Lorem 式文案
- ❌ 到处 `transition: all 0.3s` 却不定义缓动曲线

## 设计要点
1. **先定基调**：这是工具型（信息密度优先）还是展示型（留白与视觉冲击优先）？
   工具型→紧凑网格、弱装饰；展示型→大留白、强对比。
2. **色彩**：定一个主色 + 一个强调色，再配 3-4 级中性灰。
   不要用纯黑纯白：文字用 `#1a1a1a` 一类，背景用 `#fafaf9` 一类（带一点色相）。
3. **字体**：中文用系统字体栈（`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`），
   数字/代码用等宽。字号至少 5 级阶梯（如 12/14/16/20/28）。
4. **间距**：用 4 或 8 的倍数。相关元素靠近，不相关元素拉开——间距本身就是分组。
5. **层级**：靠字重 + 字号 + 颜色深浅建立层级，不要什么都加边框和阴影。
6. **交互状态**：hover / active / focus / disabled 都要有明确反馈；focus 必须可见（无障碍）。
7. **暗色模式**：用 CSS 变量 + `@media (prefers-color-scheme: dark)`。
   暗色不要简单反色：降低对比度、避免纯白文字（用 `#e5e5e5` 一类）。

## 无障碍与工程
- 语义化标签：`nav` / `main` / `section` / `button`，不要 div 一把梭。
- 图片有 `alt`；表单控件有关联 `label`；可点区域 ≥ 44×44px。
- 颜色对比度：正文 ≥ 4.5:1，大字号 ≥ 3:1。
- 响应式：至少考虑 375 / 768 / 1440 三档。
- 零构建优先：能一个 HTML 文件搞定就别上打包工具（除非项目已有构建链）。

## 交付前自检
- 截图看一眼（用 `screenshot` 或让用户在浏览器打开）——不要只靠脑补。
- 检查极窄屏（320px）和超宽屏是否崩坏。
- 控制台无报错；无外部资源加载失败。
