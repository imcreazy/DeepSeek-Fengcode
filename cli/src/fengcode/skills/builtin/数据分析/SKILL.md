# 数据分析

## 第一步：先看清数据，再动手
```
analyze_data(path="data.csv")
```
这一步会给出：行数列数、各列空值率、唯一值数、数值列的描述统计、前 5 行样本。
**不要跳过这一步**直接写分析代码——列名和数据类型经常和想象的不一样。

## 第二步：明确问题
先问自己（或问用户）："要回答什么问题？"
- 描述现状 → 统计量 + 图表
- 找关系 → 相关性、分组对比
- 找异常 → 分位数、离群点
- 做预测 → 需要说明模型与假设

## 第三步：分析（用 python_exec）
- 优先用 pandas / numpy（本机已装）；大数据量注意内存。
- **每次只回答一个问题**，不要一次算一堆指标。
- 结果要打印出来看，不要假设代码跑对了就得到了正确结果。
- 数值结果保留合理精度：比率 2 位小数，金额按需，避免输出 15 位浮点。

## 第四步：可视化成图
```
make_chart(kind="bar", data={"labels": [...], "values": [...]}, title="...", xlabel="...", ylabel="...")
```
- 选对图型：趋势用折线，对比用柱状，占比用饼图（类别 ≤6 个），分布用直方图，关系用散点。
- 标题要说清"什么 vs 什么"，不要只写"数据分析图"。
- 生成后要 `read_image` 确认图能看（中文不乱码、刻度合理）。

## 输出规范
- 先给结论（一句话），再给支撑数据，最后给方法和局限。
- 明确说明数据范围（多少行、什么时间段、有没有缺失）。
- 相关不等于因果——说到相关性时不要暗示因果。
- 数据不足以下结论就直说，不要硬凑。
